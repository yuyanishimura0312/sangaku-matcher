# 人文系産学連携ニーズ抽出：10社テストケース分析

## はじめに

本レポートは、sangaku-matcherのStage 1調査の一部として、実際の有価証券報告書（有報）テキストを用いた人文社会科学系ニーズ抽出のテストケース分析をまとめるものである。対象は10社（食品・EC/IT・不動産・商社・HR・化学・小売・建設・製薬）であり、業種の多様性を確保した。各社の「経営方針、経営環境及び対処すべき課題等」セクションのテキストを精読し、以下の7類型フレームワーク（第1章で定義）に照らしてニーズを手動抽出した後、LLM（Claude API）による自動抽出プロンプトを設計・評価した。

使用した7類型フレームワーク：
1. 社会洞察連携（Social Insight）
2. 未来洞察連携（Futures Intelligence）
3. 倫理・ガバナンス連携（Ethics & Governance）
4. デザイン人類学連携（Design Anthropology）
5. 組織・文化変革連携（Organizational Culture）
6. コミュニティ・場の設計連携（Community Design）
7. ナラティブ・コミュニケーション連携（Narrative）

## 第1部：10社個別分析

### 1.1 カゴメ株式会社（食品・農業）

**テキストの概要**

カゴメは「食を通じて社会課題を解決する」というビジョンのもと、「トマトの会社から野菜の会社へ」という変革を10年かけて推進してきた。2025年度を第3次中計の最終年度と位置づけ、ファンベースドマーケティング・DtoC・プラントベースフードといった戦略を展開しながら、気候変動による農産原材料の調達問題と向き合っている。

**検出された人文系ニーズ**

**[1] 社会洞察連携**
- 確信度：高
- 根拠テキスト：「コロナ禍が生活者の価値観や消費行動を大きく変え」「ファンベースドマーケティングによりお客様との関係強化を図る」
- 推定される連携形態：共同調査研究（消費者の食と価値観の変化についてのエスノグラフィック研究）
- 解説：「ファンベースドマーケティング」という戦略は、単なる購買行動ではなく顧客との文化的・情緒的関係性の構築を志向している。文化人類学・社会学的アプローチによる「食と生活者の関係性」の調査研究との親和性が高い。

**[2] 未来洞察連携**
- 確信度：中
- 根拠テキスト：「次の10年につなげていきたい」「気候変動の深刻化」「社会インフラの変化」
- 推定される連携形態：共同研究（食農の長期シナリオ設計）
- 解説：「次の10年」という長期視点と気候変動・社会変化の組み合わせが、未来洞察的な連携ニーズを示唆している。農業と社会変化の未来シナリオ研究との連携が考えられる。

**[3] ナラティブ・コミュニケーション連携**
- 確信度：中
- 根拠テキスト：「トマトの会社から、野菜の会社に」という10年間のブランド変革の語り
- 推定される連携形態：アドバイザリー（ブランドナラティブの深化）
- 解説：10年間の変革ストーリーを社内外に伝え続けることは、組織のナラティブ構造の問題であり、文学・レトリック研究者の知見が有効である。

**検出されなかった類型**：デザイン人類学連携（製品設計についての記述が薄い）、コミュニティ・場の設計連携（農業コミュニティへの言及はあるが産学連携ニーズとして具体化しにくい）

### 1.2 株式会社ＺＯＺＯ（EC/ファッションIT）

**[2] 倫理・ガバナンス連携**

- 解説：ファッション産業における廃棄・労働・環境の倫理問題は、哲学・倫理学・サプライチェーン研究との連携で実質的な解決策を模索できる。

- 推定される連携形態：アドバイザリー（企業アイデンティティの哲学的深化）
- 解説：「クリエイター集団」というセルフナラティブは、組織アイデンティティの観点から文学・美学・哲学研究と連携することで、実際の企業文化設計に深みを与えられる。

**検出されなかった類型**：コミュニティ・場の設計連携（デジタル空間主体でリアルコミュニティへの言及が薄い）

### 1.3 住友不動産株式会社（不動産）

**テキストの概要**

住友不動産は「430年の歴史を刻む住友グループ」という長い歴史の上に立ち、「信用と創造」「よりよい社会資産を創造し後世に残す」という基本使命を持つ。東京都心の賃貸ビル投資を中心に事業を展開しつつ、社会課題解決への貢献と企業価値最大化の両立を目指す。

**検出された人文系ニーズ**

**[1] コミュニティ・場の設計連携**
- 確信度：高
- 根拠テキスト：「よりよい社会資産を創造し、それを後世に残していく」「各事業を通じて、環境をはじめとする様々な社会課題の解決に貢献」
- 推定される連携形態：共同研究（都市空間と社会的コミュニティ形成の研究）
- 解説：「社会資産」という概念は、単なる物理的建造物を超えた社会的・文化的資本の蓄積を含意する。都市社会学・建築人類学・まちづくり研究者との連携により、都市空間の社会的価値創造を設計できる。

**[2] ナラティブ・コミュニケーション連携**
- 確信度：中
- 根拠テキスト：「430年の歴史を刻む住友グループ」「信用と創造」「デベロッパーとしての矜持」
- 推定される連携形態：アドバイザリー（長期的組織ナラティブの現代的再解釈）
- 解説：430年という時間軸でのナラティブは歴史学・組織論の視点から「現代に何を継承し何を変えるか」という問いを持っており、歴史学・哲学研究者との対話が有益である。

**[3] 倫理・ガバナンス連携**
- 確信度：低
- 根拠テキスト：「様々な社会課題の解決に貢献しつつ、企業価値の最大化」
- 推定される連携形態：アドバイザリー
- 解説：「浮利を追わず」という住友の事業精神は企業倫理の古典的な表現であり、現代的なESGガバナンスとの接続点を持つ。ただし記述の具体性が低いため確信度は低い。

**検出されなかった類型**：デザイン人類学連携（テナント・居住者のユーザー体験設計についての記述がない）

### 1.4 三井物産株式会社（総合商社）

**検出された人文系ニーズ**

**[1] 未来洞察連携**
- 確信度：高
- 根拠テキスト：「Creating Sustainable Futures」「先行き不透明なビジネス環境」「グローバル・産業横断的取組み」「サステナビリティ経営の更なる深化」
- 推定される連携形態：共同研究（グローバル社会変化のシナリオ研究・未来洞察）
- 解説：総合商社の中期経営計画は必然的に長期・複雑・グローバルな社会変化のシナリオを前提とする。社会科学的な未来洞察研究者（フューチャリスト・シナリオ研究者）との連携は、経営計画の質を高める直接的な価値を持つ。

**[2] 倫理・ガバナンス連携**
- 確信度：高
- 根拠テキスト：「サステナビリティ経営の更なる深化」「リスク管理を徹底」「グループ経営力の強化」
- 推定される連携形態：共同研究（グローバルサプライチェーン倫理・ガバナンス設計）
- 解説：食料・資源・インフラという人権と直結する事業領域を持つ三井物産にとって、倫理的ガバナンスの構築は核心的な課題である。人権研究・ビジネス倫理学との連携ニーズが高い。

**[3] 社会洞察連携**
- 確信度：中
- 根拠テキスト：「産業横断的取組み」「食料安保・資源確保・インフラ・ヘルスケア・DX」
- 推定される連携形態：共同研究（グローバルな食・エネルギー・健康の社会変化研究）
- 解説：三井物産の事業領域は世界の社会変化と直結しており、地域社会学・開発社会学・グローバルスタディーズとの連携が価値を持つ。

**[4] ナラティブ・コミュニケーション連携**

- 推定される連携形態：アドバイザリー（企業価値体系の哲学的整合性レビュー）
- 解説：「個人の自律性」「社会への期待」「まだここにない出会い」という多層の価値を一貫したナラティブとして組織全体に浸透させることは、組織論・哲学・レトリック研究の観点から設計できる。

- 推定される連携形態：アドバイザリー（スポットワーク倫理・プラットフォーム労働の規範設計）

### 2.1 業種別パターン

10社の分析から、業種によって人文系連携ニーズの出現パターンに明確な傾向が見られた。

**食品・消費財（カゴメ・小林製薬・アクシアル）** では社会洞察連携とナラティブ連携が強く出現する。食は人間の文化・生活と最も直結する産業であり、消費者との関係性・食文化の変容・ブランドの意味といった人文的テーマが経営課題に組み込まれやすい。小林製薬の特殊なケース（危機後）ではナラティブ・倫理連携が突出した。

**HR・労働（リクルート・タイミー）** では社会洞察連携と組織・文化変革連携が高い確信度で検出された。「はたらく」という概念そのものを事業の核心に置く企業は、労働・自己実現・社会関係という人文社会科学の核心テーマと必然的に交差する。

**多角化大企業（旭化成・三井物産）** では未来洞察連携と倫理・ガバナンス連携が強く出現した。複数の産業領域を横断し、長期視点で社会課題に向き合う大企業は、社会変化のシナリオ設計と倫理的ガバナンスの構築に高い需要を持つ。

**不動産・建設（住友不動産・戸田建設）** ではコミュニティ・場の設計連携が主要な類型となった。「場を作る」という事業の本質が、地域社会・コミュニティ・社会インフラという人文社会科学的テーマと直接接続する。

**EC/IT（ZOZO）** はナラティブ連携と社会洞察連携が強かった。テクノロジー企業でありながら「多様な個性」「文化的包摂」というテーマを核心に持つZOZOのケースは、技術企業においても人文的連携ニーズが高い事例を示している。

### 2.2 検出精度の評価

10社の手動分析で、確信度「高」と判定したニーズは合計25件（全35件の71%）であった。確信度「中」は8件（23%）、確信度「低」は2件（6%）であった。

確信度「低」だが潜在的に重要なシグナルとしては、戸田建設の「未来ビジョンCX150」のような長期志向の言語化が挙げられる。テキスト量が少ないため判断材料が限られるが、長期ビジョンを策定している企業は未来洞察連携ニーズを持つ可能性が構造的に高い。

誤判定リスクの高いパターンとして最も注意が必要なのは、以下の3パターンである。第一に「将来に関する事項は〜が判断したものであります」という定型的免責文への反応で、これは全有報に共通して出現し未来洞察連携とは無関係である。第二に「多様性・ダイバーシティ」の形式的記述で、女性管理職比率の数値目標だけの記述は組織文化変革の実質的ニーズを示さない。第三に「ESG対応」の定型文で、CGコードへの対応として画一的に記述されるESGは、倫理・ガバナンス連携の実質的ニーズを示さない場合が多い。

### 3.4 エラーケース・誤判定パターンの対処法

**誤判定パターン1: 定型的免責文への過反応**
対処法: 文頭の免責文ブロック（「文中の将来に関する事項は〜が判断したものであります」）を前処理段階でストリップする。

**誤判定パターン2: ESG定型記述**
対処法: 「SDGs」「ESG」「カーボンニュートラル」単体の登場をスコアに反映しない。これらが特定の事業課題・意思決定文脈に埋め込まれている場合のみスコアを付与する。

**誤判定パターン3: 抽象的な「社会課題解決」**
対処法: 「社会課題」が具体的な課題名（例：「高齢者の孤立」「食料廃棄」「ジェンダーギャップ」）と結びついている場合のみスコアを付与する。

**誤判定パターン4: テキスト量の少ない企業**
対処法: クリーンテキストが3,000文字未満の場合は確信度の天井を「中」とし、「高」は付与しない。追加情報（統合報告書・CSRレポート）との照合を推奨する注記を付ける。
