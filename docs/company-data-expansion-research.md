# sangaku-matcher 企業情報拡張 調査レポート

**作成日**: 2026-04-15
**対象**: https://sangaku-matcher.onrender.com/ (v1) / sangaku-matcher-v2 (開発中)

## 1. 現状の企業情報

sangaku-matcherは現在、EDINET有価証券報告書を主要データソースとして3,872社の上場企業データを保持している。具体的には、企業名・証券コード・業種・従業員数といった基本情報に加え、売上高・営業利益・時価総額・研究開発費・R&D集約度の財務指標、有報の「研究開発活動」セクション全文とその384次元埋め込みベクトル、LLMで推定したニーズテキスト、そして手動入力の特許IPC分布と大学との産学連携実績（共同研究・共同特許）を格納している。

9次元スコアリング（tech_prox, abs_cap, need_fit, past_ties, trl_compat, open_inno_mat, theme_fit, ambition_fit, humanities_fit）にtime_fitを加えた多面的評価は、すでに高い設計水準にある。しかし、入力データの幅が限られているため、スコアリング次元の潜在能力を十分に引き出せていない。特にpast_ties（連携実績）、open_inno_mat（オープンイノベーション成熟度）、abs_cap（吸収能力）の3次元は、追加データによる大幅な精度向上が見込まれる。

## 2. 利用可能なデータソース

調査の結果、以下のデータソースが企業情報の拡張に有効であることが判明した。コスト、技術的難易度、マッチングへの有用性の3軸で評価している。

### 2.1 公的・オープンデータ（無料〜低コスト）

**J-GLOBAL（JST）** は最も有望なソースの一つである。約86万機関の情報と研究者プロフィールを網羅し、Web APIで1日5,000件まで取得可能で無料である。企業所属研究者の研究分野、大学との共著関係、共同研究実績を横断的に取得でき、past_tiesとabs_capの精度向上に直結する。

**KAKEN（科研費データベース）** はNIIが運営する科研費採択研究のデータベースで、CiNii APIを通じてアクセスできる。企業が分担者として参画している科研費プロジェクトを特定することで、産学連携の実態をより正確に把握できる。APIは無料で、Application IDの登録が必要となる。

**gBizINFO** は経産省が運営する法人情報オープンデータで、約500万法人をカバーしている。法人番号、所在地、補助金・表彰歴、届出・届出認定情報などを提供し、REST APIまたはファイルダウンロードで取得できる。APIトークンの申請は無料で、日次更新される。企業名寄せの基盤として、またオープンイノベーション関連の補助金採択状況の把握に有用である。

**CiNii Research** はNIIの学術文献検索サービスで、論文の著者所属情報から企業と大学の共著関係を抽出できる。RSS/Atom/JSON-LD形式で取得可能で、無料（Application ID要登録）である。

**researchmap** は日本の研究者情報データベースで、共同研究・競争的資金等19種類の業績情報を持つ。APIは2025年6月に新規受付を再開しており、IP制限付きのAPIキーが発行される。研究者個人の産学連携実績を把握する上で貴重なソースとなる。

**特許庁API（J-PlatPat経由）** は2022年から提供されている特許情報取得APIで、14種類の特許関連APIが利用可能である。ただし、2024年8月に新規登録を一時停止しており、再開時期は未定である。現状ではJ-PlatPatのWeb検索やCSVダウンロード機能を活用することになる。IPC以外の特許分類（FI/Fターム）や引用情報の取得により、tech_proxの精度向上が期待できる。

### 2.2 商用データ（有料）

**帝国データバンク（TDB）** は全国全業種の企業情報データベースをAPI経由で提供している。信用調査報告書は1社あたり1.5万〜3万円、最低利用料月額3,000円から。上場企業以外も含む網羅的な企業プロフィール（代表者、業歴、取引先、評点）を取得できる。

**東京商工リサーチ（TSR）** は国内1,000万件超の企業情報を保有し、売上高・従業員数・代表者情報など詳細な属性情報を項目単位で購入可能（G-Search経由で1社1,600円〜）。非上場企業のデータ拡張に有用だが、現状の上場企業3,872社に限定するならば優先度は低い。

**Speeda（ユーザベース）** は海外1,000万社超の企業データと3,000以上の業界レポートを持ち、API連携にも対応している。個別見積りで高額だが、業界動向とセットで企業の戦略的ポジショニングを把握できる点が独自の価値となる。

**Clarivate（Derwent Innovation）** は6,500万件超の発明データを持つ特許分析プラットフォームで、API/データフィード対応。特許の質指標（被引用数、特許ファミリー、Derwent Innovation Index）を通じた技術力評価に強い。高額だがtech_proxの高精度化に最も寄与するソースの一つである。

### 2.3 Web上のテキストデータ

**統合報告書・ESGレポート** は多くの上場企業がPDFで公開しており、CSR図書館.net等のアグリゲーションサイト経由でも取得可能である。BERTモデルによるESG情報抽出では、E（環境）93.3%、S（社会）91.7%、G（ガバナンス）77.4%の適合率が報告されている。R&Dテキストと組み合わせることで、企業のサステナビリティ志向や社会課題への関心をスコアリングに反映できる。

**プレスリリース（PR TIMES等）** は上場企業の43%超が利用しており、RSSフィードまたはスクレイピングで取得可能。研究開発・共同研究・業務提携等のニュースをリアルタイムに収集でき、企業の最新動向把握に有効である。正式なAPIは提供されていないため、RSSフィード（2種類）を活用する方式が現実的となる。

**CrossRef/Semantic Scholar API** は企業所属著者の論文を所属（affiliation）フィールドから検索可能である。Semantic Scholar APIは無料で、キーワード検索・著者検索・引用ネットワーク分析に対応する。CrossRef APIもROR（Research Organization Registry）を使った所属機関フィルタリングが可能。企業の学術的アウトプットを直接測定できる貴重なソースである。

## 3. 先行事例からの知見

### 3.1 国内外のマッチングプラットフォーム

JSTの「大学見本市（イノベーション・ジャパン）」は日本最大の産学連携マッチングイベントで、132大学・281研究シーズが出展される規模を持つ。ここでのマッチングは基本的に研究者が直接ブースで対面応答する形式であり、テキストベースの自動マッチングとは異なるアプローチだが、「企業の具体的技術ニーズを正確に把握すること」がマッチング成功の鍵であるという知見は共通している。

特許庁は「特許情報を活用したビジネスマッチングレポート」を開発しており、特許分類に基づく技術近接性の評価が産学連携の初期スクリーニングに有効であることを実証している。マッチング成功率は平成29年度の21.8%から平成30年度には35.7%に向上したと報告されている。

海外では、**IN-PART** が250以上の研究機関と6,500以上のR&D企業を接続するプラットフォームとして注目に値する。STEM専門家がキュレーションを行い、アルゴリズムが「研究関心と優先事項の整合性」に基づいてマッチングを行う。企業側のR&D優先領域を構造化データとして保持している点が特徴的である。

**Wellspring** のEvolveプラットフォームはAIによる技術移転管理を提供し、潜在的な共同開発パートナーの特定やランドスケープマップ・セクター分析を自動生成する。機械学習によるライセンサブルな発明の発見機能を持つ。

**InnovationQ+**（Clarivate）はIEEEコンテンツと全世界の特許・非特許文献を統合した発見・分析プラットフォームで、独自のSemantic Gist(R)エンジンにより意味的な技術近接性を評価する。特許ポートフォリオのビジネスインテリジェンス機能を持つ点が、sangaku-matcherのabs_cap・open_inno_mat評価に参考になる。

### 3.2 学術的エビデンス

学術研究からは、産学連携マッチングにおいて以下の企業属性が有効であることが示されている。

**吸収能力（Absorptive Capacity）** は全ての高パフォーマンス連携パスウェイに共通する基盤的能力であり、企業規模や所有形態、大学の威信度、各種近接性は文脈依存的な役割を果たす。これはfuzzy-set QCA（質的比較分析）を用いた構成的視点からの研究で明らかにされている。

**技術的近接性** については、中小企業では技術的近接度が高いほど異なる大学との技術移転活動が活発になるが、大企業では近接度が低くても専門性が高ければ移転が成立するという非対称性が指摘されている。sangaku-matcherのtech_proxスコアリングにおいて、企業規模に応じた重み付けの調整を検討する根拠となる。

**多次元的近接性** として、技術的近接性に加え、制度的近接性（institutional proximity）と社会的近接性（social proximity）を考慮すべきことが示唆されている。これは現在のスコアリングにおけるpast_ties（社会的近接性の代理変数）やopen_inno_mat（制度的近接性の代理変数）の重要性を学術的に裏付けるものである。

## 4. 推奨する拡張アプローチ

### 4.1 技術的基盤

**企業名寄せ（Entity Resolution）** はあらゆるデータ統合の前提となる。gBizINFOの法人番号を基軸IDとし、証券コード・EDINET codeとのマッピングテーブルを構築する。Python用のEntity Resolutionライブラリとしては**Splink**（2025年英国公務員賞受賞）が最も成熟しており、確率的レコードリンケージに対応する。

**埋め込みモデルのアップグレード** については、現行の384次元（おそらくall-MiniLM-L6-v2等）から、日本語特化モデルへの移行を推奨する。名古屋大学チームの**Ruri-v3-70M**はパラメータ数70Mでありながら、multilingual-e5-largeと英語で互角、日本語ではそれを上回る性能を示している。37Mのruri-v3-30mでもOpenAIのtext-embedding-v3-largeを超えるJMTEBスコアを達成しており、コスト効率が極めて高い。

**複数テキストソースの統合** については、R&Dテキスト・統合報告書・プレスリリース・特許明細書など複数ソースのテキストをweighted average embeddingで統合するアプローチが現実的である。ソースごとに重み付けを設定し（例：R&Dテキスト0.4、特許0.3、プレスリリース0.2、ESG0.1）、マッチング用途に応じて重みを動的に変更できる設計が望ましい。

**DBアーキテクチャ** については、現行のSQLiteは3,872社規模では十分であるが、テキストカラムの追加やベクトル検索の高速化を見据え、**DuckDB**への移行も選択肢となる。DuckDBは列指向ストレージで分析クエリに強く、SQLiteとの互換性が高い。ただし、現行規模であればSQLiteのまま十分に運用可能であり、移行の優先度は低い。

### 4.2 段階的実装ロードマップ

#### Phase A: 低コスト・高インパクト（推奨最優先）

| データソース | 取得情報 | スコアリングへの寄与 | コスト | 難易度 |
|---|---|---|---|---|
| Semantic Scholar API | 企業所属著者の論文・引用 | abs_cap, tech_prox | 無料 | 容易 |
| gBizINFO | 法人番号・補助金・所在地 | 名寄せ基盤, open_inno_mat | 無料 | 容易 |
| CiNii Research API | 産学共著論文 | past_ties | 無料 | 容易 |
| PR TIMES RSS | 研究開発プレスリリース | need_fit, theme_fit | 無料 | 容易 |

Phase Aは全て無料のAPIまたはRSSで取得可能であり、既存のPythonスクリプト群（scripts/fetch_rd_section.py等）の延長として実装できる。特にSemantic Scholar APIとCiNii Research APIの組み合わせにより、past_tiesスコアの精度を大幅に向上させることが期待できる。

#### Phase B: 中コスト・高インパクト

| データソース | 取得情報 | スコアリングへの寄与 | コスト | 難易度 |
|---|---|---|---|---|
| J-GLOBAL API | 研究者プロフィール・共同研究 | past_ties, abs_cap | 無料 | 中程度 |
| KAKEN API | 科研費プロジェクト・分担者 | past_ties, theme_fit | 無料 | 中程度 |
| researchmap API | 研究者の産学連携業績 | past_ties | 無料（要IP申請） | 中程度 |
| 統合報告書PDF | ESG/中期計画テキスト | ambition_fit, humanities_fit | 無料 | 困難 |

Phase BはAPIアクセスの申請手続き（researchmapのIP制限、KAKENのApplication ID等）が必要となるため、Phase Aと並行して申請を進めておくことを推奨する。統合報告書PDFの自動取得・テキスト抽出は技術的難易度が高いが、pdfplumberの活用経験（EDINET有報処理）をそのまま活かせる。

#### Phase C: 高コスト・高精度化

| データソース | 取得情報 | スコアリングへの寄与 | コスト | 難易度 |
|---|---|---|---|---|
| Derwent Innovation | 特許の質指標・引用NW | tech_prox | 高額（要見積） | 中程度 |
| TDB/TSR | 詳細企業プロフィール | abs_cap, open_inno_mat | 1社1,600円〜 | 容易 |
| Speeda | 業界分析・戦略情報 | ambition_fit | 高額（要見積） | 容易 |
| Ruri-v3モデル移行 | 埋め込み精度向上 | 全次元 | 無料（計算資源） | 中程度 |

Phase Cは商用データの導入であり、費用対効果を慎重に検討する必要がある。Ruri-v3モデルへの移行は無料だが、3,872社分の再埋め込み計算が必要となるため、Phase Bの完了後に実施するのが合理的である。

## 5. 結論と推奨

sangaku-matcherの企業情報拡張において、最もインパクトが大きく即座に着手できるのは**Phase A**の4つのオープンデータソース統合である。特に以下の3つの施策を最優先として推奨する。

1. **Semantic Scholar + CiNii Researchによる産学共著論文データの取得** — 企業所属著者のaffiliationフィールドから産学共著関係を自動抽出し、past_tiesスコアの精度を大幅に向上させる。現状の手動CSV入力を自動化・網羅化できる。

2. **gBizINFOによる法人番号マッピングの構築** — 全データソース統合の基盤となるEntity Resolution基盤を整備する。法人番号をキーとして、EDINET code・証券コードとの名寄せテーブルを作成する。

3. **PR TIMES RSSによるリアルタイム企業動向の取得** — 研究開発・共同研究関連のプレスリリースをテキストとして蓄積し、need_fitスコアの時系列的な鮮度を向上させる。

これらの施策は全て無料で実装可能であり、既存のアーキテクチャ（Python + SQLite + sentence-transformer）をそのまま活用できる。埋め込みモデルのRuri-v3への移行は、Phase Bと並行して検証を進めることを推奨する。
