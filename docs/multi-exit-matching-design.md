# 多出口型マッチングアルゴリズム設計

## ステータス: Stage 0 確定（2026-04-12）

## 背景・課題

現在のアルゴリズムは7次元価値モデルの重み付き線形結合で単一スコアを算出し、事後的にif-elseで連携形態を推定する構造。以下の構造的問題がある:

1. **単一スコアへの圧縮**: 7次元の情報が1つの数値に潰れ、多面性が失われる
2. **事後的なモード推論**: ランキング後にモードを推定 — 連携形態が「おまけ」
3. **出口が研究者視点で設計されていない**: 研究者が実際に必要としているのは「何について話すべきか」「どういう関係を築けるか」
4. **重み付けが固定**: 人類学者とAI研究者で同じ重み

## 決定事項

### 3つの出口（連携形態）

出口は以下の3つ。具体性のグラデーション上に並ぶ:

```
具体的 ←────────────────────────→ 抽象的
  R&D共研     新領域共研     探索的対話
```

#### 1. 共同研究（R&D）

企業側に明確な技術課題・ニーズがあり、研究者のシーズが直接それに応える連携。成果は論文・特許・プロトタイプなど具体的。

- 問いは既に定義されている
- 研究者は「解を持つ人」として参加
- 契約・予算・期間が明確になりやすい

#### 2. 共同研究（新領域探索）

企業が挑戦しようとしている新領域（野心領域）に、研究者の知見で貢献する連携。課題はまだ定義途上で、研究者が問いの設定自体に関わる。

- 問いそのものを共に作る
- 研究者は「問いを立てる人」「フレームを提供する人」として参加
- 成果は新しい問いの発見・フレームワーク・PoC

#### 3. 探索的対話

具体的な共同研究の形はまだ見えないが、テーマ的な親和性がある。まず対話して接点を探る段階。

- 「話してみたら面白そう」の段階
- 複数のテーマ軸で接点がある方が価値が高い（深さより広さ）
- 成果は相互理解・将来の連携の種

### 表示方法

出口別に独立したセクションで結果を提示する。

### 新しいスコアリング次元

#### ambition_fit（野心領域適合）

40の野心テーマへの研究者親和度×企業近接度。ambition_taxonomy_themes / ambition_taxonomy_proximity を使用。新領域共研で最も重要。企業が「やりたいがまだできていない」領域と研究者の専門が重なる箇所を見つける。

#### theme_breadth（テーマの広がり）

122テーマの中で、研究者親和度と企業近接度の双方が閾値を超えるテーマの数。1つのテーマで深く一致するよりも、複数テーマで「話ができそう」な方が探索的対話では価値が高い。

計算例:
```python
breadth = count(theme for theme in all_122_themes
               if researcher_affinity[theme] > 0.83
               and company_z_score[theme] > 0.55)
# 正規化: breadth / max_possible_breadth
```

## 各出口の仮説生成ロジック

### R&D共研の仮説

「企業Xは[技術テーマ]に関するニーズを持っており（need_fit=0.XX）、当該シーズの[具体的技術]が直接対応できる。R&D投資も高く（abs_cap=0.XX）、連携実績もある（past_ties=0.XX）ため、共同研究の契約に至りやすい候補。」

→ 技術テーマを具体的に示す。ニーズとシーズの対応関係が明確。

### 新領域共研の仮説

「企業Yは[野心領域テーマ]に挑戦しようとしており（ambition_fit=0.XX）、この新領域において[研究者の専門]の知見が[humanities_role]。OI体制も整備されており（open_inno=0.XX）、新しい取り組みへの組織的な受容性が高い。」

→ 野心テーマとhumanities_roleを活用。「まだない問い」を一緒に作る関係。

### 探索的対話の仮説

「企業Zとは[N]個のテーマで接点がある（theme_breadth=N）: [テーマ1]、[テーマ2]、[テーマ3]...。特に[人文テーマ]と[野心テーマ]の交差領域で、対話から新たな連携テーマが見つかる可能性がある。」

→ 接点テーマを列挙。特定の1テーマではなく「話の広がり」を提示。
