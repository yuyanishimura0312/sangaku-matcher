1. データベースの全体像

sangaku-matcherのデータベースはSQLite形式で、以下の4つの主要データ領域で構成されています。すべてのデータは公開情報（有価証券報告書、特許情報、論文データベース）から取得・推定されたものです。

企業データ

{{ stats.companies }}社の上場企業情報。基本情報（業種・売上・従業員数）に加え、R&D投資額、AIが推定した技術ニーズ・人文社会ニーズ・新規事業野心を含みます。

テーマ体系

122テーマ（技術49・社会33・野心40）の3軸分類体系。各テーマにはキーワードと埋め込みベクトル（重心）が付与されています。

テーマ近接度

{{ stats.proximity_total|default('485,000+', true) }}件の企業-テーマ近接度データ。各企業がどのテーマにどれだけ近いかを数値化しています。

連携実績

{{ stats.collaborations }}件の大学-企業共同研究・特許の実績データ。過去の連携実績をスコアリングに活用しています。

3. 企業データ

企業データはEDINET（金融庁の電子開示システム）から取得した有価証券報告書を解析して構築しています。各企業について以下の情報を保持しています。

基本情報

  • edinet_code: EDINET固有コード（主キー）
  • sec_code: 証券コード
  • name: 企業名
  • industry: 業種分類
  • revenue: 売上高（百万円）
  • employees: 従業員数

R&D関連情報

  • rd_expense: 研究開発費（百万円）
  • rd_intensity: R&D投資比率（研究開発費/売上高）
  • rd_text: 有報のR&D記述テキスト
  • rd_text_vector: R&Dテキストの埋め込みベクトル（384次元）

AI推定ニーズ

有報のテキストをAI（Claude）で分析し、以下の3種類のニーズを推定しています。各ニーズにはテキスト説明と埋め込みベクトルが付与されています。

  • tech_needs: 技術ニーズ（必要としている技術領域）
  • humanities_needs: 人文社会ニーズ（社会的課題への関心）
  • ambitions: 新規事業の野心（中期経営計画からの推定）

その他

  • open_inno_score: オープンイノベーション度（外部連携の積極性）
  • midterm_plan_text: 中期経営計画のテキスト

4. テーマ体系データ

テーマ体系は、有価証券報告書のテキストをGTA（Grounded Theory Approach）に着想を得たボトムアップ分析で構造化したものです。3つの軸で合計122テーマが定義されています。

技術テーマ（49テーマ）

企業のR&D記述から抽出した技術領域の分類です。「AI・機械学習」「半導体・電子デバイス」「バイオテクノロジー」などの大分類の下に、具体的な技術テーマが配置されています。

社会課題テーマ（33テーマ）

企業が取り組む社会的課題の分類です。「カーボンニュートラル」「健康・ウェルビーイング」「デジタル格差」などのテーマが含まれます。人文社会系の研究者にとって、技術テーマだけでは見えない連携先の発見に有用です。

野心テーマ（40テーマ）

企業の中期経営計画や統合報告書から抽出した、新規事業・成長領域のテーマです。「宇宙ビジネス」「量子コンピューティング」「フードテック」など、企業が将来的に展開したいと考えている領域を反映しています。

テーマ近接度

各企業と各テーマの間の近接度（proximity）が計算されています。近接度は0.0〜1.0の値で、企業のテキスト情報とテーマの重心ベクトルとのコサイン類似度に基づいています。

5. マッチングデータ

ユーザーが入力した研究テーマ（seed）と、マッチング結果が保存されています。

seeds（研究テーマ）

入力された研究テーマのタイトル、説明文、DOI（論文の場合）、特許番号（特許の場合）、埋め込みベクトルが保存されます。過去に入力したテーマの結果は結果一覧から再閲覧できます。

multi_exit_matches（3出口ルート結果）

3つの出口ルート（R&D、新領域探索、探索的対話）ごとに、スコア上位の企業とその内訳（10次元スコア）、AIが生成した連携仮説が保存されています。

6. 連携実績データ

大学と企業の過去の連携実績（共同特許・共著論文）のデータです。EDINET企業コードと大学名をキーに、連携の種類（特許/論文）、件数、最終年度を記録しています。この実績データは、スコアリングの「連携実績」次元に反映されます。

現在{{ stats.collaborations }}件の連携実績が登録されており、過去に特定の大学と連携実績がある企業は、同大学の研究者とのマッチングで「連携実績」スコアが加点されます。

7. データソース

データソース取得方法
企業基本情報EDINET（金融庁）IR Collector経由で有報を自動取得・解析
R&D情報有価証券報告書テキスト抽出+埋め込みベクトル化
推定ニーズ有報テキストClaude AIによる構造化分析
テーマ体系有報テキスト集約GTA風ボトムアップ分類+手動精査
連携実績特許庁・CiNii等公開データの名寄せ・集約
業種統計計算済み企業データからの集計

埋め込みモデルにはintfloat/multilingual-e5-small（384次元）を使用しています。日本語テキストの意味的類似度計算に最適化された多言語モデルです。
