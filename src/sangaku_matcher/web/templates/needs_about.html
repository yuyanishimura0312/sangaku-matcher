{# ── Overview ── #}
概要

sangaku-matcherの need_fit スコアラーは、企業の推定技術ニーズと入力シーズの意味的類似度を算出します。推定ニーズは「ニーズテキスト」と「ニーズベクトル（384次元）」のペアで構成されます。

現行版（v2）では、EDINET API v2から有価証券報告書の経営方針セクションを取得し、Claude APIで個社別のニーズテキストを生成しています。有報が取得できなかった企業にはv1テンプレートがフォールバックとして適用されます。

{# ── v2 Generation Logic ── #}
生成ロジック（v2: EDINET + Claude API）

v2では、有価証券報告書の原文テキストからClaude APIを使い、企業ごとに固有のニーズテキストを生成します。

1. 有報テキスト取得（EDINET API v2）

EDINET API v2の書類一覧API（documents.json）を日付スキャンし、各企業の有価証券報告書（docTypeCode: 120）を特定します。取得した書類からCSV形式（type=5）またはXBRL形式（type=1）で以下のセクションを抽出します。

優先度XBRLタグセクション名
1jpcrp_cor:BusinessPolicyBusinessEnvironmentIssuesToAddressEtcTextBlock経営方針、経営環境及び対処すべき課題等
2jpcrp_cor:ManagementAnalysisOfFinancialPositionOperatingResultsAndCashFlowsTextBlock経営者による財政状態、経営成績及びCFの状況の分析
3jpcrp_cor:ResearchAndDevelopmentActivitiesTextBlock研究開発活動

スキャン期間: 2024-04-01 〜 2026-04-01（約2年間）。{{ v2_count }}社の有報テキストを取得済み。

2. Claude APIによる構造化抽出

取得した経営方針テキスト（最大4,000字）をClaude Haiku 4.5に入力し、以下の構造で200〜400字の個社別ニーズテキストを生成します。

{企業名}の推定技術ニーズ。[R&Dの方向性の要約]。[新規事業領域への言及]。求める技術領域: [具体的な技術キーワード 5-10個]

テンプレート的な記述ではなく、経営方針テキストに言及されている具体的な技術分野、新規事業領域、DX施策、成長戦略に基づいて推定します。

3. ベクトル化

生成されたテキストを intfloat/multilingual-e5-small（384次元多言語モデル）でエンコードし、needs_vector として保存します。マッチング時にはこのベクトルと入力シーズのベクトルのコサイン類似度が need_fit スコアとなります。

{# ── v1 Fallback ── #}
フォールバック（v1: テンプレートベース）

有報テキストが取得できなかった {{ v1_count }}社には、業種テンプレートによるフォールバックが適用されます。3つの要素を組み合わせて自動生成します。

1. 業種テンプレート

主要業種ごとに、その業種に典型的な技術ニーズのキーワードリストを定義しています。業種が一致する企業には同一のキーワード群が割り当てられます。

2. R&D特性修飾

R&D投資比率（rd_intensity）に応じて3段階の文脈テキストを付与します。

R&D比率修飾テキスト
> 5%先端技術の外部導入に積極的
> 2%技術課題の解決パートナーを求めている
その他外部技術による事業革新を模索している
3. 規模修飾
売上高修飾テキスト
> 1兆円大手企業として、大規模な共同研究や技術ライセンスの受入体制がある
> 1000億円中堅〜大手として、特定領域の技術パートナーシップを重視
その他成長企業として、大学発技術のスピーディーな事業化に関心
{企業名}の推定技術ニーズ。{R&D特性修飾}。{規模修飾}。求める技術領域: {業種テンプレート}

{# ── Scoring Integration ── #}
マッチングスコアへの組み込み

推定ニーズデータは、五層価値モデルの 第1層：技術的価値（need_fit）として、重み0.20で総合スコアに反映されます。

スコアラー層重み算出方法
tech_proxL1 技術0.25R&Dベクトルとの逆U字類似度
need_fitL1 技術0.20ニーズベクトルとの線形類似度
abs_capL3 知識0.20R&D投資 + 認知的近接性
open_innoL5 生態系0.15OI成熟度 + 連携幅 + ハブ度
past_tiesL2 関係0.10連携量 + 多様性 + 最新度
future_optionL4 将来0.10R&D幅 + 探索距離 + 柔軟性
