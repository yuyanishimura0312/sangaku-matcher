# sangaku-matcher（産学マッチャー）

大学の技術シーズを入力として、大企業の公開情報（IR・有報・特許・統合報告書）からバックキャストで潜在ニーズを推定し、産学連携の可能性を仮説化するシステム。

**ステータス**: Stage 0（仕様策定）完了 / Stage 1（調査・設計）待機中

---

## このプロジェクトは何か

大学の研究成果を産業界と接続する「産学連携」において、コーディネーターや大学TLO担当者は「どの大企業に技術を持ち込むべきか」を判断する材料に乏しい。各社のIR・有報を一社ずつ読み込む作業は非現実的で、結果として「知っている企業」「過去に縁のある企業」に偏りがちである。

本プロジェクトは、大学の技術シーズを入力すると、500社規模の対象企業の公開情報を解析し、連携可能性の高い候補企業を根拠付きでランキング出力するツールを目指す。差別化点は、企業が課題を投稿しなくても「公開情報から潜在ニーズを推定する」バックキャスト型アプローチであり、これは既存の商用サービス（IN-PART, Halo, NineSigma, リンカーズ, Bibbidi等）が実装していない領域。

調査では12商用サービス、16学術論文、12事例を3並列リサーチで収集し、三角検証で「ニーズプル型がシーズプッシュ型を圧倒する」「技術的近接性・吸収能力・連携実績の3特徴量がスコアの三本柱」「公開情報からの潜在ニーズ推定は商用前例なし」という3つの確度高の知見を得ている。
